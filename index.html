📌 Tentang Aplikasi

Aplikasi ini membantu menganalisis Rapor Pendidikan dari file unduhan Kemendikdasmen. Data akan dikelompokkan berdasarkan predikat capaian: Baik, Sedang, dan Kurang.

🔧 Fitur Utama

  • Upload file .docx, .pdf, .xlsx/.xls
  • Analisis otomatis per kategori
  • Kesimpulan naratif + Matriks Prioritas
  • Grafik visual (Pie, Bar, Dimensi)
  • Rekomendasi tindak lanjut PBD/ARKAS
  • Perbandingan multi-sekolah
  • Export ke Excel dan PDF

📝 Cara Penggunaan

1. Klik menu 📋 Analisis Rapor di sidebar

2. Upload file Rapor Pendidikan

3. Klik tombol Analisis Sekarang

4. Lihat hasil di tab Capaian/Baik/Sedang/Kurang

5. Cek Kesimpulan, Grafik, dan Rekomendasi

🏫 Perbandingan Multi-Sekolah

Upload 2+ file rapor sekaligus untuk membandingkan rata-rata skor antar sekolah. Sekolah dengan skor 3 terendah akan di-highlight merah, dan 3 tertinggi di-highlight hijau.
